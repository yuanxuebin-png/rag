# 燕云十六声调优笔记（测试用）

> 用途: 丢进 pocket-rag 的 sample_docs 里, 测「只有这份笔记里有答案的问题」能不能被答对并引用来源。

## 硬件底线

机器是 RTX 4060 笔记本版, 内存 16GB。目标是在《燕云十六声》里稳定 110 帧以上,
所以画质选项的取舍原则是: 保帧率先于保画质, 内存压力大的选项一律关闭。

## 设置取舍

阴影质量是帧率杀手, 调到中档, 不要开高。
体积云和全局光照关掉, 这两项最吃显卡但对战斗体验几乎没影响。
人群密度调到最低, 既能省显存又能省内存, 主城里帧率能多出十来帧。
垂直同步关闭, 改用驱动面板的帧率上限锁在 120, 画面延迟比开垂直同步低很多。

## 内存相关

16GB 内存下建议关掉浏览器再进游戏, Chrome 开着十几个标签页至少吃 3GB。
游戏本体放在 D 盘, 通过目录联接(junction)迁移过路径, 这个对加载速度没有影响,
只是为了让路径短一点, 防止某些老引擎因为路径过长读档失败。

## 键位习惯

闪避绑定在鼠标侧键, 招式派生用滚轮下压。闪刀的节奏口诀是 10/90/90/30 毫秒,
四段间隔分别对应起手、前摇、判定和收招的窗口。

## 排查口诀

掉帧先看显存占用是不是爆了, 再看 CPU 单核是不是顶满, 最后才怀疑显卡整体算力。
爆显存降纹理, 单核满降人群密度, 都不顶用再把驱动回退一个版本试试。
