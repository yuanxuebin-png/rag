HTTP 基础笔记

一、请求方法
GET 用于获取资源, 参数放在 URL 上, 幂等且可缓存。
POST 用于提交数据创建资源, 参数放在请求体里, 不幂等。
PUT 是整体替换, PATCH 是局部更新, DELETE 删除资源。
这五个方法里 GET、PUT、DELETE 是幂等的, POST 和 PATCH 不是。

二、常见状态码
200 成功; 201 已创建, POST 建资源成功常返回它。
301 永久重定向, 302 临时重定向。
400 请求参数有错(客户端问题); 401 未认证(没登录或 token 失效); 403 已认证但没权限; 404 资源不存在。
409 冲突, 比如并发更新同一条记录。500 服务器内部错误, 502 网关收到上游无效响应, 504 网关超时。

三、请求头里最常用的几个
Content-Type 声明请求体格式, JSON 接口用 application/json。
Authorization 放认证凭据, Bearer token 是最常见的方案。
Cache-Control 控制缓存策略, no-cache 表示要用前先问服务器。

四、调试方法
curl -v 能看到完整请求和响应头。
浏览器开发者工具的 Network 面板能看每个请求的状态码、耗时和负载。
后端加日志时记得打印请求 id, 方便在分布式日志里串起同一次请求。
