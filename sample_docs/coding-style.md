# Python 编码规范摘要

## 命名

变量和函数用小写下划线: `user_order_count`。
类名用大驼峰: `OrderService`。常量全大写: `MAX_RETRY = 3`。
私有成员加单下划线前缀 `_cache`, 提示外部不要直接用。
布尔变量加 is/has/can 前缀, 读起来像句子。

## 函数设计

一个函数只做一件事, 超过 40 行就要考虑拆。
参数不要超过 5 个, 太多就收拢成一个 dataclass 或 TypedDict。
返回值类型要稳定: 要么都返回值, 要么都返回 None 抛异常, 不要两种混着来。
避免用可变对象当默认参数, `def f(x=[])` 会让所有调用共享同一个列表, 正确写法是默认 None 然后函数内新建。

## 异常处理

只捕获你明确知道怎么处理的异常, 裸 `except:` 是事故源头。
不要用异常做正常流程控制, 异常是给「真的出了问题」准备的。
捕获后要么处理要么重新抛出并加上下文, 静默吞掉最糟糕。
自定义异常继承 Exception, 起名以 Error 结尾。

## 注释与文档

docstring 写「是什么、什么时候用、参数含义、返回什么」, 注释写「为什么这么做」。
代码本身能表达的事不要重复注释, 注释和代码不一致比没有注释更害人。
公开函数必须有 docstring; 一次性脚本的内部函数可以省。
